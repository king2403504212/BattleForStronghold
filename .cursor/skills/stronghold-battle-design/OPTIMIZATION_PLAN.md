# 据点争夺 Demo 优化方案

记录日期：2026-11-6

本文只记录后续优化方向。具体功能尚未确认，暂不修改现有策划与代码。

## 一、战斗表现优化

### 当前问题

- 士兵抵达目标城池后仍停留在城池上，遮挡城池画面。
- 交战阶段主要依赖文字和伤害飘字，战斗表现较弱。

### 建议方案

1. 士兵保持当前路线和终点，正常移动到目标城池。
2. 抵达城池时立即隐藏或销毁行军士兵，不在城池上停留。
3. 在目标城池上方循环播放攻城帧动画。
4. 战斗期间继续显示双方伤害飘字。
5. 战斗结算后停止并隐藏攻城动画，再显示占领成功或进攻失败。

### 实现边界

- 行军士兵消失只影响画面，进攻方剩余兵力继续保存在战斗数据中。
- 攻城动画使用已经准备好的素材制作独立预制体，通过属性检查器绑定。
- 攻城动画只在交战期间出现，重开、胜利、失败或组件销毁时必须清理。
- 动画位置跟随目标城池的场景位置，不使用旧配置坐标。

## 二、玩法循环优化

### 当前问题

- 目前主要玩法是选择兵力并比较双方数值，策略变化较少。
- 单独增加“消耗道具恢复兵力”没有完整的道具来源，也缺少使用压力。
- 当前总兵力不足以持续占领多个高兵力城池，需要增加可主动获得的补充手段。
- 现有规则同时只允许一支队伍行动，加入敌方 AI 会占用行动阶段并增加玩家等待。

### 推荐方案：占领奖励与主动征兵

形成以下循环：

`主动占领城池 → 立即获得军粮 → 选择补充哪座城池 → 继续进攻`

基础规则建议：

- 每座非玩家城池首次被占领时，立即奖励一定数量的军粮，不需要等待产出。
- 玩家选择己方城池后，可以消耗军粮补充该城兵力。
- 每座城设置兵力上限，超过上限不能继续征兵。
- 不同城池可以配置不同的占领奖励、征兵效率或兵力上限。
- 军粮、征兵数量和消耗数值统一放入只读配置。

### 增加乐趣的补充方式

- 军粮除征兵外，还可以消耗在一次性战术上，让玩家决定恢复兵力还是强化下一次进攻。
- 不同城池提供不同的首次占领奖励，引导玩家选择进攻顺序。
- 通关时根据剩余兵力、派遣次数或消耗军粮数量给出评价，增加重复挑战价值。
- 本轮不加入敌方 AI，避免玩家等待敌方行军和战斗。

## 三、建议实施顺序

1. 优化士兵抵达后的消失表现。
2. 接入目标城池上方的攻城帧动画。
3. 增加首次占领军粮奖励、军粮显示与征兵操作。
4. 增加城池兵力上限和相关数值配置。
5. 根据试玩结果调整占领奖励、征兵消耗和兵力上限。
6. 视试玩结果决定是否增加一次性战术和通关评价。

## 四、实施前待确认

- 攻城帧动画素材的格式、帧数、播放速度和预制体结构。
- 各城池首次占领时奖励多少军粮。
- 征兵是固定数量，还是允许玩家输入补充数量。
- 各城池的兵力上限和征兵消耗。
- 军粮是否同时用于一次性战术。
